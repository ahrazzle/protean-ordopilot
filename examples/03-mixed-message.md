# Example 3 — Mixed note: Orda asks instead of guessing

Notebooks: `store-stock`, `store-staff`, `store-close` ("Night close list: bins, shutters, fridge temps, cash count.").

Transcript:

> **Owner:** Mina can cover till 2 Saturday, and order more milk if we run low.
> **Orda:** Two topics in one note. Which notebook?
> 1. `store-staff` (Saturday cover)
> 2. `store-stock` (milk order)
> Reply with 1, 2, or "both".
> **Owner:** both
> **Orda:** Done. Cover note filed under `store-staff`. Milk note filed under `store-stock`.
> **Pick:** clarification park, then filed per the owner's reply — two close matches, so no guess.

Rule shown: when two notebooks fit, Orda parks the note and asks. It never files a split note on a guess.
